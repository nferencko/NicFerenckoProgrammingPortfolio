Trivia Maze Game
=====================================

The Trivia Maze Game project is a Maven project created in IntelliJ.  

**To test that you've cloned correctly:**

- try running Player.java located in src/main/java/model
- try running JUnit tests by running PlayerTest.java in src/test/java


File Structure
---------------------------------

### src/main/java

  - three sub-folders: model, view, control.  Code should be placed in the appropriate folder.

### src/test

  - JUnit tests should be placed here.  Using JUnit 5

### support

  - Support files (e.g. checkstyle files) go here.
